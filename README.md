# Avax Chess for Android

Free chess app: play Avax AI at four levels, challenge a friend on one phone, or find an opponent online. No account, no ads.

**Download:** [avax-chess.apk (latest)](https://github.com/yezayar191004-prog/avax-chess-releases/releases/latest/download/avax-chess.apk)

Website: https://avax-chess.onrender.com

## Install
1. Download `avax-chess.apk` on your Android phone (Android 7.0 or newer).
2. Open the file. If Android asks, allow installs from your browser.
3. Tap **Install**, then **Open**.

This repository only hosts the Android download. Coming soon to Google Play and the App Store.
